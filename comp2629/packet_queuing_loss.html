Arrival Rate
Rate at which packets arrive at the router input. When this exceeds the link capacity, congestion begins.

Buffer / Queue
Finite memory in the router. Excess packets wait here. When full, newly arriving packets are dropped.
🚫
Packet Loss
Occurs when the buffer overflows. Lost packets must be retransmitted, degrading application performance.
